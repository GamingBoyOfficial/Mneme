# Roadmap

## MVP (Completed)

- Rust core with SQLite and vector search
- Python SDK with three‑verb API
- Portability engine (`export`/`import`)
- Deduplication
- Audit logging
- HTTP server with real embeddings
- JS client and web dashboard
- Benchmarks and tests

## Phase 2 (In Progress)

- Postgres + pgvector backend
- Multi‑agent scoping and explicit shared memory grants
- Automatic summarization (episodic → semantic)
- LangChain / MCP adapters
- Procedural memory type
- gRPC API

## Future

- Cloud sync
- Redis backend
- More embedding models
